A program that draws one newspaper front page summing up world news of Tuesday 24 November 2026 as a 1024x1024 image: six verified stories (Nvidia, Ukraine, Hormuz, Gaza, Zaporizhzhia, COP31) plus the ICJ Myanmar finding.

## Run it

```sh
node main.ts
```

`main.ts` copies `entry.png` to `$MAKEFUN_OUTPUT_DIR` (or `/output`). To redraw the image from scratch: `python3 build_image.py`.
